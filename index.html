Clustering Schools Based on Performance and Demographics

Designed as part of a Big Data Analytics module, this project focused on clustering K-12 schools based on academic performance and demographic attributes. The dataset, comprising 101 schools and 19 variables—including math and English test scores, student-teacher ratios, racial composition, and free/reduced lunch eligibility—was compiled from platforms like US News, GreatSchools, and Niche. Through the application of Agglomerative Hierarchical Clustering, the project aimed to uncover latent patterns among schools to better inform policy decisions and educational resource allocation.
Key deliverables included robust data preprocessing, such as handling missing values and encoding categorical features, followed by clustering implementation and evaluation using dendrograms and silhouette scores. The final model highlighted systemic disparities in school performance, revealing correlations between socioeconomic status and academic outcomes. The project demonstrates expertise in unsupervised learning, domain-specific analytics, and the translation of data insights into actionable recommendations for educational improvement.

Tech Utilised: Python, Scikit-learn, Pandas, Matplotlib, Agglomerative Clustering, Dendrograms, Silhouette Score

Target Data Breach: Human Factors in Cybersecurity

An in-depth analytical project examining the 2013 Target Corporation data breach, this work utilized the Human Factors Analysis and Classification System (HFACS) to dissect the human and organizational failures contributing to the incident. The breach, which compromised data of over 40 million customers, was traced to vulnerabilities stemming from third-party vendor access, lack of real-time alert responses, and weak internal security culture.
The analysis categorized contributing factors into four HFACS levels: Unsafe Acts, Preconditions, Unsafe Supervision, and Organizational Influences. Findings highlighted issues such as phishing awareness gaps, insufficient vendor controls, and the neglect of alerts from security tools like FireEye. The project concluded with recommendations for strengthening cybersecurity infrastructure, including implementing MFA for vendors and improving threat detection protocols. This case study showcases the application of human factors analysis in real-world cybersecurity, bridging technical assessment with behavioral and organizational insights.

Tech Utilised: HFACS Framework, Cybersecurity Risk Analysis, Security Policy Evaluation, Incident Response Analysis

Snap Split

Enter Snap Split—an innovative mobile application revolutionizing number forecasting through the power of deep learning. Designed for Android devices, this cutting-edge app goes beyond image recognition—it predicts numbers extracted from images with unparalleled accuracy. Snap Split doesn't just identify numbers; it organizes them into folders, streamlining your digital experience.

What sets Snap Split apart is its strategic use of parallel processing. Embracing a collaborative approach, it divides images into four segments, dispatching each to distinct servers for decentralized number prediction. The results are then harmonized, ensuring heightened precision. Finally, Snap Split intelligently archives images into appropriate sub-folders based on the conclusive predictions. Embrace the future of numerical foresight with Snap Split.

Tech Utilised: PyTorch, Android Studio, Java, Flask

SportZify

Introducing the 'SportZify' project, a revolutionary Xamarin-based, cross-platform mobile application designed to simplify sports complex and gym time slot bookings. Embracing the MVVM (Model-View-ViewModel) architecture, this project ensures a seamless and engaging user experience. 'SportZify' marks a leap in innovation within cross-platform mobile app development, showcasing a shared codebase for both iOS and Android versions.

SportZify encompasses diverse pages, such as CricketPage.xaml, BadmintonPage.xaml, and GymPage.xaml, offering insights into sports complexes. Detailed views like SportZifyCricketDetail.xaml and SportZifyGymDetail.xaml provide in-depth information. The app features a dedicated slot booking view, named BookSlot.xaml. Three pivotal models—BadmintonCourt.cs, CricketClub.cs, and GymPlace.cs—establish getters and setters, streamlining interaction with the SQLite Database. This lightweight localized database seamlessly syncs with the central master database, ensuring efficient data management and retrieval.

Tech Utilised: Xamarin, C#, XAML, Canva, SQLite, Xcode, Android Emulator
